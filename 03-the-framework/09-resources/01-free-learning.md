# Free Learning Resources

All links below are **free** (or have a generous free tier).

## Web Security (Beginner → Advanced)

| Resource | Why |
|---|---|
| [PortSwigger Web Security Academy](https://portswigger.net/web-security) | The best free web security course. Hands-on labs for every bug class. |
| [OWASP Top 10](https://owasp.org/www-project-top-ten/) | The 10 most common web bugs. Read the whole list. |
| [OWASP Juice Shop](https://owasp.org/www-project-juice-shop/) | An intentionally vulnerable app you can practice on. |
| [HackTheBox Academy](https://academy.hackthebox.com/) | Free modules on many topics. |
| [TryHackMe](https://tryhackme.com/) | Guided beginner rooms. |

## Linux & Command Line

| Resource | Why |
|---|---|
| [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) | Learn Linux by playing a game. Start here. |
| [Linux Journey](https://linuxjourney.com/) | Free text course. |
| [The Linux Command Line (book, free PDF)](https://linuxcommand.org/tlcl.php) | Classic. |

## Networking

| Resource | Why |
|---|---|
| [Professor Messer Network+](https://www.professormesser.com/network-plus/n10-008/n10-008-video/n10-008-training-course/) | Free video course. |
| [Wireshark Labs](https://www.wireshark.org/) | Packet analysis practice. |

## Programming (for security)

| Language | Resource |
|---|---|
| Python | [Automate the Boring Stuff](https://automatetheboringstuff.com/) |
| JavaScript | [javascript.info](https://javascript.info/) |
| Bash | [Bash Scripting Guide](https://tldp.org/HOWTO/Bash-Prog-Intro-HOWTO.html) |

## CTF & Practice

| Resource | Why |
|---|---|
| [PicoCTF](https://picoctf.org/) | Beginner CTF. Free. |
| [HackTheBox](https://www.hackthebox.com/) | Realistic machines. |
| [VulnHub](https://www.vulnhub.com/) | Free vulnerable VMs. |
| [PentesterLab](https://pentesterlab.com/) | Some free exercises. |

## YouTube Channels

- **LiveOverflow** — security research mindset
- **John Hammond** — CTF walkthroughs
- **IppSec** — HackTheBox walkthroughs
- **STÖK** — bug bounty vlogs
- **NahamSec** — bug bounty for beginners
- **InsiderPhD** — beginner-friendly security
